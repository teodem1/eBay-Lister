# Listing rules

## Facts
- Seller grades are the only condition facts. Never add defects, "tested", extras or soften wording.
- Unknown value: leave it out or mark NEEDS CONFIRMATION.

## Title (80 characters maximum)
- Buyers' searches weigh the first 40 characters most: artist and album come first, as the CD names them.
- Use the remaining space for true search terms: edition phrase, year, label, `Remastered`, `Deluxe Edition`, `Import`, `Soundtrack`, a specific style (`Prog Rock`, not `Rock` or `Music`).
- Give a long edition phrase shorter forms after `||`, longest first.
- Graded: `Artist Album [extras] CD (Disc: Near Mint / Inlay: Near Mint)`; the script switches to `(NM/NM)` only to keep a term or the full album.
- Extras in priority order: supported edition phrase, year, label, then other searched terms. The script writes 2CD.
- Search words buyers type. No hype (amazing, premium, wow, L@@K, classic, legendary), no all caps beyond acronyms, no symbols or emoji.
- "Rare" at most once, only inside a supported edition phrase.
- "Canadian Version" only when bought in Canada AND Canadian-titled sold copies went higher; do not set Country of Manufacture from this.
- "Rare No Barcode" only when the whole back cover is visible without a barcode; add "Early Press" only when the label or design shows the 1980s. Then say "no barcode on the back cover" in the description. If the cover is cropped, blurry or missing, add the check "Confirm the back cover has no barcode".

## Item specifics
Artist, Release Title, Format, Genre, Style, Record Label, Release Year, Country/Region of Manufacture, Edition, Language, Type, Number of Discs, Catalog Number, Case Type, Features, Producer. Leave Brand and MPN empty.
- Use eBay's listed value, spelled the same, when you know the list.
- Values must mean what the field means: Style is a musical style, never a decade; Type is Album, Live, Compilation or Single. Skip Unit Quantity and Unit Type.
- Pressing facts (label, country, year, catalogue number) come only from the CD itself or an opened source matching its barcode or catalogue number.

## Description (phone-readable, in this order)
Simple HTML using only <h2>, <p>, <ul>, <li> and <strong>. The summary is a <p>; each later section starts with an <h2>. Name a proven edition in the summary and in Key features.
1. One-line summary leading with the fact a collector cares most about (edition, pressing, label, year), in plain words.
2. Key features: one verified fact per bullet.
3. Specifications: mirrors the filled item specifics.
4. Condition: the seller's grades and words only.
5. What's included: only what the seller states.
6. Shipping: ships only to Canada and the United States; buying more than one CD combines shipping into one package.
No external links, scripts or tables.

## Open checks
At most 4 short questions, the ones a buyer cares about most first. Never ask about language, case grade or case type of a standard CD. When the seller notes defects, include "Add a close-up photo of each defect".

## Photos
Front cover, back cover, disc, inlay, spine or catalogue number, matrix code, extras, close-up of each defect.
